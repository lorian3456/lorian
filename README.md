# אתר לוריאן – הפעלה ופריסה

## 1. שליחת פניות בדוא"ל (חובה לפני עלייה)
הטופס שולח ל-`/api/contact` (קובץ `api/contact.js`, פונקציית Serverless של Vercel). הפונקציה שולחת הודעה דרך Resend. כתובת היעד נשמרת בשרת בלבד, ואינה מופיעה באף קובץ באתר.

1. פתחו חשבון ב-resend.com ויצרו API Key.
2. ב-Vercel: Project, Settings, Environment Variables, והוסיפו את שלושת המשתנים הבאים (ראו `.env.example`):
   - `RESEND_API_KEY` – המפתח מ-Resend.
   - `CONTACT_TO` – תיבת הדוא"ל הפנימית שמקבלת את הפניות.
   - `CONTACT_FROM` – כתובת שולח.
3. כתובת השולח, אחת משתי אפשרויות:
   - **לבדיקה מהירה:** `onboarding@resend.dev`. עובד רק אם חשבון ה-Resend נפתח עם אותה כתובת דוא"ל שמקבלת את הפניות.
   - **לשימוש קבוע:** לאמת את הדומיין ב-Resend (Domains), להוסיף את רשומות ה-DNS שיוצגו שם אצל ספק ה-DNS, ולהשתמש בכתובת כמו `אתר לוריאן <no-reply@lorianltd.com>`.
4. אחרי הפריסה (Redeploy) שלחו פנייה אמיתית מכל אחד משני הטפסים וודאו שהיא מגיעה. עד שזה נבדק אין להניח שהמערכת עובדת.

אם מחליפים ספק דוא"ל, משנים רק את הקריאה ב-`api/contact.js` ומעדכנים את סעיף 4 במדיניות הפרטיות.

## 2. פריסה
העלו את כל התיקייה לריפו שמחובר ל-Vercel. אין צורך בהגדרת build. `vercel.json` מגדיר כותרות אבטחה וכתובות נקיות.

## 3. מה עוד להשלים
בהצהרת הנגישות (`accessibility.html`) יש סימונים צהובים `[להשלים: ...]`: פרטי התקשרות ישירים של רכז הנגישות ופרטי בדיקת נגישות. לא הוספתי פרטים שלא נמסרו.
